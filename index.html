📖 Kirish — Dict nima?

Python lug'atlari (dictionary) — bu kalit-qiymat juftliklarida ma'lumot saqlaydigan eng kuchli ma'lumot tuzilmalaridan biri.

📌 Dict nima?

Dict — bu kalit (key) va qiymat (value) juftliklaridan tashkil topgan o'zgaruvchan (mutable) ma'lumot turi. Jismoniy lug'atga o'xshaydi: so'z (kalit) → tarjima (qiymat).

python
# Oddiy dict yaratish talaba = { "ism": "Ali", "yosh": 20, "kurs": 2 } print(talaba)
Natija{'ism': 'Ali', 'yosh': 20, 'kurs': 2}

🔑 Kalit va Qiymat tushunchasi

Kalit (Key) — bu har bir qiymatni aniqlash uchun ishlatiladigan noyob identifikator. U string, son yoki tuple bo'lishi mumkin. Qiymat (Value) — bu kalitga bog'langan ma'lumot, har qanday tur bo'lishi mumkin.

python
# Kalit va qiymat mahsulot = { "nomi": "Telefon", # kalit: "nomi", qiymat: "Telefon" "narxi": 5000000, # kalit: "narxi", qiymat: 5000000 "mavjud": True # kalit: "mavjud", qiymat: True } print(mahsulot["nomi"]) # Telefon
NatijaTelefon

🌐 Qayerlarda ishlatiladi?

Dict Python dasturlashning deyarli har bir sohasida ishlatiladi:

  • 🔹 API javoblarini qayta ishlash (JSON)
  • 🔹 Ma'lumotlar bazasi yozuvlari
  • 🔹 Konfiguratsiya fayllari
  • 🔹 Kesh (cache) tizimi
  • 🔹 Telegram bot ishlab chiqish
  • 🔹 Web dasturlash (Django, Flask)
  • 🔹 Ma'lumotlar tahlili

🔗 JSON bilan bog'liqligi

JSON (JavaScript Object Notation) formati Python dict bilan deyarli bir xil tuzilishga ega. API bilan ishlaganda JSON ma'lumotlar avtomatik ravishda dict ga aylanadi.

python
import json # JSON string → Dict json_str = '{"ism": "Vali", "yosh": 25}' data = json.loads(json_str) print(data) print(type(data)) # Dict → JSON string back = json.dumps(data, ensure_ascii=False) print(back)
Natija{'ism': 'Vali', 'yosh': 25} <class 'dict'> {"ism": "Vali", "yosh": 25}

📚 Nazariy qism — Dict metodlari

Python dict ning barcha asosiy metodlari va ularning ishlatilishi.

🔨 dict() konstruktori bilan yaratish

Dict ni figurali qavslar {} yoki dict() konstruktori bilan yaratish mumkin.

python
# 1-usul: figurali qavslar d1 = {"a": 1, "b": 2} # 2-usul: dict() konstruktori d2 = dict(a=1, b=2) # 3-usul: list of tuples d3 = dict([("a", 1), ("b", 2)]) print(d1, d2, d3)
Natija{'a': 1, 'b': 2} {'a': 1, 'b': 2} {'a': 1, 'b': 2}

📥 get() — Xavfsiz qiymat olish

get() metodi kalit mavjud bo'lmasa xato bermaydi, balki None yoki belgilangan qiymatni qaytaradi.

python
talaba = {"ism": "Sardor", "yosh": 19} # Xavfsiz olish print(talaba.get("ism")) # Sardor print(talaba.get("manzil")) # None print(talaba.get("manzil", "Noma'lum")) # Noma'lum
NatijaSardor None Noma'lum

📋 items(), keys(), values()

Bu metodlar dict ning tarkibiy qismlarini ko'rish imkonini beradi.

python
meva = {"olma": 3, "banan": 5, "anor": 2} print(meva.keys()) # Kalitlar print(meva.values()) # Qiymatlar print(meva.items()) # Juftliklar
Natijadict_keys(['olma', 'banan', 'anor']) dict_values([3, 5, 2]) dict_items([('olma', 3), ('banan', 5), ('anor', 2)])

🔄 update() — Yangilash

update() metodi boshqa dict yoki kalit-qiymat juftliklari bilan mavjud dict ni yangilaydi.

python
profil = {"ism": "Olim", "yosh": 22} profil.update({"shahar": "Toshkent", "yosh": 23}) print(profil)
Natija{'ism': 'Olim', 'yosh': 23, 'shahar': 'Toshkent'}

🗑️ pop() va clear()

pop() — kalitni o'chirib, qiymatini qaytaradi. clear() — barcha elementlarni o'chiradi.

python
rang = {"qizil": 1, "yashil": 2, "ko'k": 3} val = rang.pop("yashil") print("O'chirilgan:", val) print("Qolgan:", rang) rang.clear() print("Tozalangan:", rang)
NatijaO'chirilgan: 2 Qolgan: {'qizil': 1, "ko'k": 3} Tozalangan: {}

📋 copy() va setdefault()

copy() — dict ning nusxasini yaratadi. setdefault() — kalit mavjud bo'lmasa yangi kalit-qiymat qo'shadi.

python
# copy() original = {"a": 1, "b": 2} nusxa = original.copy() nusxa["c"] = 3 print("Original:", original) print("Nusxa:", nusxa) # setdefault() d = {"ism": "Ali"} d.setdefault("yosh", 18) d.setdefault("ism", "Vali") # o'zgarmaydi print(d)
NatijaOriginal: {'a': 1, 'b': 2} Nusxa: {'a': 1, 'b': 2, 'c': 3} {'ism': 'Ali', 'yosh': 18}

🏗️ Nested Dict (Ichma-ich lug'at)

Dict ichida dict saqlash mumkin — bu murakkab ma'lumotlar uchun juda qulay.

python
maktab = { "5-sinf": { "sinf_rahbar": "Kamola opa", "talabalar_soni": 30 }, "6-sinf": { "sinf_rahbar": "Sardor aka", "talabalar_soni": 28 } } print(maktab["5-sinf"]["sinf_rahbar"])
NatijaKamola opa

⚡ Dict Comprehension

Bir qatorda yangi dict yaratish uchun comprehension ishlatiladi.

python
# Sonlarning kvadratini dict ga yozish kvadrat = {x: x**2 for x in range(1, 6)} print(kvadrat) # Shartli comprehension juft = {x: x**2 for x in range(1, 11) if x % 2 == 0} print(juft)
Natija{1: 1, 2: 4, 3: 9, 4: 16, 5: 25} {2: 4, 4: 16, 6: 36, 8: 64, 10: 100}

🔗 zip() bilan dict yaratish

Ikki ro'yxatni birlashtirish uchun zip() juda qulay.

python
ismlar = ["Ali", "Vali", "Soli"] yoshlar = [20, 22, 19] talabalar = dict(zip(ismlar, yoshlar)) print(talabalar)
Natija{'Ali': 20, 'Vali': 22, 'Soli': 19}

🔄 for bilan aylanish

python
baholar = {"Matematika": 5, "Fizika": 4, "Kimyo": 3} # Kalitlar bo'yicha for fan in baholar: print(fan, "->", baholar[fan]) # items() bilan for fan, baho in baholar.items(): print(f"{fan}: {baho} ball")
NatijaMatematika -> 5 Fizika -> 4 Kimyo -> 3 Matematika: 5 ball Fizika: 4 ball Kimyo: 3 ball

🔁 while bilan ishlash

python
savat = {"olma": 3, "nok": 5, "uzum": 2} while savat: element = savat.popitem() print(f"Olib tashlandi: {element}") print("Savat bo'sh:", savat)
NatijaOlib tashlandi: ('uzum', 2) Olib tashlandi: ('nok', 5) Olib tashlandi: ('olma', 3) Savat bo'sh: {}

🔧 def bilan ishlash

python
def talaba_info(**kwargs): """Kalit so'z argumentlarni dict sifatida qabul qiladi""" for kalit, qiymat in kwargs.items(): print(f"{kalit}: {qiymat}") talaba_info(ism="Jasur", yosh=21, kurs=3)
Natijaism: Jasur yosh: 21 kurs: 3
